# Security policy

This project has not been audited and should not hold material value without independent review.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Use GitHub's private vulnerability reporting: **Security tab > Report a vulnerability** on
https://github.com/Alimzy/stellar-crowdfund. Include a description, impact, and a reproduction
(a failing test is ideal). You can expect an acknowledgement within a few days.

## Scope

In scope: the contract in `contracts/crowdfund`. Out of scope: Soroban, the Stellar network,
token contracts, and third-party tooling.

See [docs/SECURITY-MODEL.md](docs/SECURITY-MODEL.md) for assumptions and known limits.
